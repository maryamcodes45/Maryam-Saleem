# 🍳 Recipe Finder - MERN Stack Application

A full-stack **Recipe Finder Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

This application allows users to search, explore, and manage recipes with a modern responsive interface. It includes a complete backend API, MongoDB database integration, authentication, and CRUD operations.

---

## 🚀 Features

### 👤 User Features
- Search recipes by name
- Explore different meals and recipes
- View detailed recipe information
- Responsive modern UI
- Manage favorite recipes

### 🔐 Authentication
- User registration and login
- Secure user authentication
- Protected routes

### 📝 Recipe CRUD Operations
- Create recipes
- Read recipe details
- Update recipes
- Delete recipes

### ⚙️ Backend Features
- REST API development
- MongoDB database integration
- Data handling using Mongoose
- Express.js server

## ⚡ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/maryamcodes45/Recipe-Finder.git
```

---

## Frontend Setup

Go to frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm run dev
```

---

## Backend Setup

Open another terminal and go to backend folder:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Start backend server:

```bash
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **backend** folder:

```
MONGO_URI=your_mongodb_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```
